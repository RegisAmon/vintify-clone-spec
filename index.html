Vintify-clone — Spec MVP

Clone mécanique d'un SaaS « photos pro IA pour vendeurs Vinted ». Le produit de référence définit la spec ; nom/copy/design réécrits de zéro.

1. Résumé exécutif

L'utilisateur photographie un vêtement à plat → l'IA analyse (type, genre, taille, état, marque, couleurs) → génération de photos « catalogue » : portées par un mannequin IA avec pose et ambiance choisies, ou à plat → l'IA rédige titre, description et hashtags → annonce complète dans « Mes annonces », prête à copier-coller. Monétisation : abonnements mensuels (6 tiers) + packs ponctuels, quotas par plan.

2. Personas

  • Vendeur occasionnel — 2-10 annonces/mois, sensible au prix → Starter / packs.
  • Power seller — 50+ annonces/mois, mannequins réutilisables, qualité 4K → tiers hauts.
  • Admin — users, quotas, poses/fonds, prompts, storage, coût réel.

3. Features MVP

3.1 Wizard 5 étapes (chaque étape ré-ouvrable via « Modifier »)

  1. Photo de l'article — upload / prise photo / collage, max 5. Analyse vision auto : type (haut / bas / couvre-chef), genre, taille, état, couleurs, marque, capuche/poches.
  2. Détails — pré-remplis, éditables. États : Neuf avec étiquette / Neuf sans étiquette / Très bon état / Bon état / Satisfaisant.
  3. Type de photo — Porté par mannequin / À plat (plié face, dos, manches rentrées).
  4. Modèle — Adulte / Enfant, genre, ou mannequin sauvegardé (plans IA).
  5. Pose + ambiance — poses multiples (Face, Dos, 3/4, Selfie sans visage, Capuché, Assis, plié…) ; 12 ambiances (Studio, Fond noir/blanc/gris, Chambre vintage, Dressing, Salon, Balcon parisien, Nature, Table shooting, Magazine).

3.2 Génération

  • Jobs async : createTask + callback, progression SSE, idempotence, coût réservé au lancement puis débité au réel au callback.
  • Qualité par plan : 1K / 2K / 4K. Améliorations IA par presets (« couleurs fidèles », « moins de plis », « tissu naturel », « print net », « t-shirt opaque »).

3.3 Mannequins IA (plans IA)

  • Création via photo de référence OU paramétrique : genre, âge 18-52, origine, yeux, cheveux, morphologie, expression, détails distinctifs, style (E-commerce / Lifestyle / Neutre), curseur de variation 0-100% selon plan.
  • Galerie « Mes mannequins » réutilisables dans le wizard.

3.4 Rédaction & annonces

  • Titre + description + hashtags par LLM (quota rédactions).
  • Mes annonces : fiche complète, copie/telechargement, historique.

3.5 Crédits

  • Quotas : images, annonces, rédactions, mannequins — trackés en DB (jamais le client).
  • Free : 2 annonces + images offertes. Échec API = refund automatique.

8. Sécurité & légal (revue critique)

  • Proxy BFF relaie toujours l'Authorization Bearer au backend ; gating backend sur les médias (URLs signées, jamais le « blur CSS »).
  • Idempotency sur tout achat/génération ; webhooks Stripe vérifiés ; aucune route legacy non signée.
  • Quotas : DB fait foi ; le seed admin n'écrase jamais un hash ; 429 rate-limit ≠ bug de mdp.
  • RGPD : export (art. 20) + suppression en cascade (art. 17) + CGU/Privacy/Cookies.
  • Marque : aucun nom, logo, texte ou asset de la cible. Mécaniques seules clonées. Mention produit : « le vêtement source n'est jamais altéré » (garantie Cloth-Preserve).

9. Critères de succès

  • E2E : inscription → free credits → wizard → annonce générée (images + texte) < 60s/génération.
  • Échec API = refund vérifié en DB.
  • Isolation : le compte B ne voit jamais les données de A (404, jamais 403).
  • Paiement test : crédits en < 5s, double-clic = un seul paiement.
  • Wizard complet utilisable en 480px.
